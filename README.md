# library_seat

건국대학교 도서관 좌석 모니터링·예약 보조 도구입니다.
React + Vite 기반 휴대폰 웹앱과 기존 Windows GUI를 제공합니다. 로그인·예약 API는 Flask, 계정 상태와 자동 실행은 Supabase, 배포는 Vercel을 사용합니다.

## 휴대폰 웹앱

**휴대폰에서 좌석을 선택하고 자동 예약을 시작하면, 화면을 끄거나 PC를 꺼도 클라우드가 대기합니다.**
배포와 Supabase Cron 활성화, 유효한 도서관 로그인이 필요합니다. 예약 성공은 경쟁 상황에 따라 달라집니다.
예약은 임시배정이며, 배정 확정은 도서관에서 공식 앱으로 NFC 인증해야 합니다.

- 1·2·3·5열람실 전체 좌석 검색, 기존 1인석 모아보기, 빈자리 필터
- 하단의 좌석 찾기 / 내 좌석 / 설정으로 기능 분리, 탐색 중 현재 좌석 미니바 표시
- 좌석 상세창에서 즉시 예약·빈자리 대기, 별도 선택 모드로 여러 열람실 좌석 대기
- 대기 중에도 좌석 상세창에서 바로 추가·제외, 마지막 좌석 제외 시 종료 (이미 끝난 대기는 다시 시작하지 않음)
- 선택한 좌석이 0~1분 남았거나 비어 있으면 1초 주기, 나머지 대기는 30초 주기
- 여러 좌석 중 하나가 확보되면 모든 대기 종료
- 새 배정은 내 좌석으로 이동, 자동 재예약은 탐색 화면을 유지하며 완료 알림·확인 시각 표시
- 임시배정 / 배정 확정 / 상태 확인 불가를 구분하여 표시
- 임시배정 취소, 확정 좌석 반납 (실행 전 최신 상태와 다시 대조)
- 도서관 아이디·비밀번호 로그인, 선택적 자동로그인 및 계정별 상태 분리
- 로그인 실패 시 등록·저장 방지, 비밀번호 재입력 안내
- 예약 결과가 불명확한 경우 중복 요청을 막기 위해 대기 중지
- 웹앱 로그아웃·브라우저 종료 후에도 클라우드 대기 유지

**배포 절차: [DEPLOY.md](DEPLOY.md)**

운영 웹앱: https://library-seat-dusky.vercel.app

각자 도서관 계정으로 로그인하면 자신의 좌석·예약·대기만 사용할 수 있습니다. 별도 가입이나 PC 연결은 필요하지 않습니다.
자동로그인을 선택한 경우 성공한 로그인 정보만 서버에 암호화해 저장하고, 도서관 인증 만료 시 재연결합니다.
로그인에 실패하면 계정을 등록하거나 잘못 입력한 비밀번호를 저장하지 않습니다.
웹앱에서도 임시배정이 확인되면 `내 좌석 → 임시배정 자동 재예약`이 기본으로 켜져 배정 9분 후 같은 좌석을 취소·재예약합니다. NFC 인증 후 종료됩니다.
스위치를 끄면 해당 배정에서는 꺼진 상태를 유지하며, 새로 예약에 성공하면 다시 자동으로 켜집니다. 배정 시간·좌석 정보를 확인하지 못하거나 취소·예약 결과가 불명확하면 자동 실행을 중지합니다.
기존 좌석이 있어도 다른 좌석을 선택해 자동 예약을 시작할 수 있습니다. 대기 중에는 현재 좌석을 유지하고, 선택한 자리가 비면 기존 좌석을 취소·반납한 뒤 갈아타기를 시도합니다.
새 좌석 예약이 명확히 실패하면 원래 좌석 재예약을 시도하고, 복구에 성공하면 대기를 계속합니다. `바로 예약`에서도 갈아타기와 실패 시 복구를 지원합니다.
취소 사이에 다른 사람이 잡으면 좌석을 잃을 수 있으며, 원래 좌석 복구도 보장되지 않습니다. 복구한 좌석은 다시 임시배정되므로 현장 NFC 인증이 필요합니다.

### 로컬 미리보기

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
npm ci
npm run build
$env:LIBRARY_WEB_PASSWORD="local-demo-password-change-me"
$env:LIBRARY_COOKIE_SECURE="0" # 로컬 HTTP 미리보기에서만 사용
python webapp.py --demo
```

`http://127.0.0.1:8080`에 접속한 뒤 위 접속 비밀번호를 입력합니다.
데모는 가상 좌석이며 도서관에 요청하지 않습니다. 실제 로컬 실행은 `--demo`를 빼고 웹 화면에서 도서관에 연결합니다.
로컬 실행에서는 **PC가 켜져 있어야** 자동 예약이 유지됩니다.

화면 소스는 `frontend/src/`, 아이콘·설치 메타데이터는 `frontend/static/`에 있습니다. Node.js 24를 사용합니다.
`npm run build`가 `public/`을 새로 생성하므로 결과물을 직접 수정하지 않습니다. 화면 변경 후 빌드 결과도 함께 커밋합니다.
현재 Vercel Flask 배포가 빌드 전 파일 목록으로 정적 파일을 수집하므로 `public/` 결과물을 저장소에도 포함합니다.
React 개발 서버가 필요하면 Flask를 `python webapp.py --demo --port 8765`로 실행한 뒤 다른 터미널에서 `npm run dev`를 실행합니다.
Vite가 같은 출처의 `/api` 요청을 로컬 Flask로 전달합니다. 운영 환경에서는 Vercel이 빌드한 정적 화면과 Flask API를 함께 제공합니다.

```powershell

python -m unittest discover -s tests -v

```

Chrome이 설치된 환경에서 모바일 폭(320·390px)과 데스크톱 화면을 검증합니다. 탭 전환과 검색 유지, 상세창, 예약·자동 재예약, 여러 좌석 선택, 기존 좌석 유지 대기·갈아타기, 확정 상태·반납을 데모로 확인합니다.
실제 도서관 서버에 예약 요청을 보내지 않습니다.

## 기존 Windows GUI 기능

- 관심 좌석(`WATCH_LIST`) 상태 모니터링
- 좌석별 `예약 대기` 등록/해제
- 여러 좌석 대기 중 하나가 예약 성공하면 나머지 대기 자동 해제
- 임시배정(`TEMP_CHARGE`) 상태에서 반복(취소 후 재예약) 기능
- 임시배정 상태 진입 시 반복 기능 자동 시작
- 수동 예약, 반납(또는 임시예약 취소), 다시 잡기
- 환경 변수 기반 자동 로그인(선택)

## 환경 변수 (선택)

자동 로그인을 사용하려면 아래 값을 설정합니다.

```powershell
$env:KONKUK_LIBRARY_ID="학번/아이디"
$env:KONKUK_LIBRARY_PW="비밀번호"
```

영구 저장이 필요하면 `setx` 사용:

```powershell
setx KONKUK_LIBRARY_ID "학번/아이디"
setx KONKUK_LIBRARY_PW "비밀번호"
```

## 실행

```powershell
python library.py
```

실행 흐름:

1. Chrome을 열어 로그인/토큰을 확보
2. 내 예약 페이지를 1회 확인
3. GUI 모니터 실행

## 좌석 목록 수정

`library_config.py`의 `WATCH_LIST`는 기존 GUI의 감시 목록이며, 웹에서는 기존 **1인석 모음**의 표시 기준으로 사용합니다.
웹의 전체 좌석은 이 목록으로 제한하지 않습니다. 공식 열람실 목록에서 확인한 1A(102), 1B(101), 2(232), 3A(233), 3B(234), 5(107)의 좌석을 조회합니다.
선택 좌석이 0~1분 구간이면 해당 열람실만 집중 확인합니다. 1초는 목표 간격이며 서버 응답·실행 지연 시 길어집니다.
아이콘은 SVG와 32·180·192·512px PNG를 제공합니다. 개발용 Pillow 설치 후 `python scripts/build_icons.py`로 다시 만들 수 있습니다.
